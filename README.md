# PIR Motion Detection System Using Arduino UNO

## Internship Task 1

A PIR-based motion detection system developed using Arduino UNO and simulated using Tinkercad Circuits.

## Components Used

- Arduino UNO
- PIR Motion Sensor
- LED
- Buzzer
- Resistors
- Breadboard
- Jumper Wires

## Working Principle

The PIR sensor detects movement in its surrounding area and sends a signal to the Arduino UNO.

The Arduino reads the sensor value and controls the LED and buzzer according to the detected condition.

### No Motion Detected
- LED remains OFF
- Buzzer remains OFF

### Motion Detected
- LED turns ON
- Buzzer produces an alert sound
